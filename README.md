# GeoSuite

A browser-based location data utility for international users.

## CSV to GeoJSON

Open `index.html` in a browser. Drop a CSV file with latitude and longitude columns, choose the matching columns, and download GeoJSON. Files are processed locally in the browser.

## Deploy

This is a static site. Cloudflare Pages can serve the repository root directly; no build command is required.
